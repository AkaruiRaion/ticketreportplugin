# TicketReport — плагин отчётов по закрытым заявкам для GLPI 9.4

Плагин добавляет в меню GLPI пункт **«Отчёты»**, позволяющий выгрузить в
Excel (XLSX) список заявок выбранного пользователя, закрытых в указанном
месяце/году (по полю `closedate`).

## Требования

- GLPI 9.4.x
- PHP 7.2–7.4
- Composer (только на этапе установки, для загрузки PhpSpreadsheet)

## Установка

1. Скопируйте папку `ticketreport` целиком в директорию плагинов GLPI:

   ```
   <корень_glpi>/plugins/ticketreport/
   ```

2. Установите зависимость PhpSpreadsheet через Composer прямо внутри
   папки плагина (это единственный шаг, требующий доступа в интернет):

   ```bash
   cd <корень_glpi>/plugins/ticketreport
   composer install --no-dev --optimize-autoloader
   ```

   После этого в папке плагина должен появиться каталог `vendor/`.

3. Зайдите в GLPI под учётной записью с правами суперадминистратора:
   **Настройка → Плагины**.

4. Найдите «Отчёты по закрытым заявкам (TicketReport)» и нажмите
   **Установить**, затем **Активировать**.

5. При установке плагин автоматически:
   - регистрирует отдельное право доступа `plugin_ticketreport`;
   - выдаёт это право профилю **Super-Admin**.

6. После активации в меню появится пункт **«Отчёты»** (в разделе
   «Плагины»). Доступ к нему есть только у пользователей, чьему профилю
   выдано право `plugin_ticketreport` (по умолчанию — только Super-Admin).

## Управление доступом других профилей

Перейдите в **Администрирование → Профили → [нужный профиль]** — появится
вкладка **«Отчёты по заявкам»**, где можно выдать/забрать доступ к разделу
отчётов для этого профиля.

## Как пользоваться отчётом

1. Откройте пункт меню **«Отчёты»**.
2. Выберите пользователя, месяц и год.
3. Нажмите **«Сформировать отчёт»**.
4. Браузер автоматически скачает файл `closed_tickets_report_userN_MM_YYYY.xlsx`
   со столбцами: **Дата закрытия | Наименование заявки | ID заявки**.

## Архитектура (SOLID)

| Файл                        | Ответственность                                            |
|-----------------------------|-------------------------------------------------------------|
| `setup.php`                 | Метаданные плагина, регистрация хуков/меню/прав             |
| `hook.php`                  | install/uninstall, регистрация права доступа                |
| `inc/report.class.php`      | ТОЛЬКО получение данных из БД (SQL через query builder GLPI) |
| `inc/excel.class.php`       | ТОЛЬКО построение и отдача XLSX (PhpSpreadsheet)             |
| `inc/menu.class.php`        | ТОЛЬКО описание пункта меню                                  |
| `inc/profile.class.php`     | ТОЛЬКО вкладка управления правом на странице профиля         |
| `front/report.php`          | ТОЛЬКО HTML-форма (View)                                     |
| `front/report.export.php`   | ТОЛЬКО координация вызовов Report → Excel (Controller)       |
| `front/profile.form.php`    | ТОЛЬКО сохранение права профиля                              |

Ни один файл не смешивает SQL, HTML и логику экспорта одновременно.
